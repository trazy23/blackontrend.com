# Black on Trend site content workflow

Purpose: keep blackontrend.com visually aligned with the live Instagram account.

The site should not invent separate placeholder stories. The featured visuals should come from approved/published BOT Instagram posts or founder-approved launch material.

## What Muse/Zoe should provide when a new post is published

For each site-worthy post, provide:

- Instagram URL
- Desk/category
- Short site headline, 6–12 words
- One-line site angle, 1 sentence
- Final approved cover image or still frame
- Alt text
- Whether it should be Hero feature / Latest card / Archive only

## Asset path

Copy final site images to:

`assets/latest/`

Use short filenames, e.g.:

- `poitier-festival.jpg`
- `wnba-playoffs.jpg`
- `timnit-gebru-ai.jpg`

Recommended crop: 4:5 portrait, 960x1200px, compressed JPG.
